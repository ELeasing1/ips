# Сайт ИП Смолянинов — инструкция

Файлы в этой папке:

| Файл | Что это |
|---|---|
| `index.html` | сам сайт (всё внутри: тексты, фото, анимации) |
| `admin.html` | админка: добавление выполненных работ и отзывов |
| `data/content.json` | список работ и отзывов (его заполняет админка, руками трогать не нужно) |
| `README.md` | эта инструкция |

Фото, которые добавляются через админку, сами появляются в папках `uploads/works` и `uploads/reviews`.

---

## 1. Разместить сайт на GitHub (один раз, ~10 минут)

1. Зарегистрируйтесь на [github.com](https://github.com) (кнопка **Sign up**).
2. Справа вверху **+** → **New repository**.
   - **Repository name** — например `site`.
   - Обязательно **Public** (бесплатный хостинг работает только для публичных).
   - Нажмите **Create repository**.
3. На странице нового репозитория нажмите ссылку **uploading an existing file**
   (или **Add file → Upload files**).
4. Перетащите в окно **всё содержимое этой папки**: `index.html`, `admin.html`, `README.md` и папку `data`.
   Внизу нажмите зелёную **Commit changes**.
5. Включите хостинг: **Settings → Pages** (меню слева) →
   **Source: Deploy from a branch** → **Branch: main**, папка **/ (root)** → **Save**.
6. Через 1–2 минуты сверху на той же странице появится адрес сайта, например
   `https://ваш-логин.github.io/site/`. Готово — сайт работает.

> Хотите адрес без `/site` в конце? Назовите репозиторий `ваш-логин.github.io` —
> тогда сайт будет открываться по `https://ваш-логин.github.io/`.

## 2. Ключ доступа для админки (один раз)

Админка сохраняет фото прямо в ваш репозиторий, поэтому ей нужен ключ (токен):

1. На GitHub: аватар справа вверху → **Settings** → в самом низу слева **Developer settings**.
2. **Personal access tokens → Fine-grained tokens → Generate new token**.
3. Заполните:
   - **Token name** — например `admin сайта`;
   - **Expiration** — срок действия (можно выбрать максимальный; когда истечёт — просто создадите новый);
   - **Repository access → Only select repositories** → выберите репозиторий сайта;
   - **Permissions → Repository permissions → Contents → Read and write**.
4. **Generate token** → скопируйте ключ (начинается на `github_pat_…`).
   GitHub показывает его один раз — сохраните в заметках телефона.

## 3. Как пользоваться админкой

1. Откройте `https://ваш-логин.github.io/site/admin.html`
   (то есть адрес сайта + `admin.html`).
2. Репозиторий подставится сам. Вставьте ключ → **Войти**.
   Галочка «Запомнить» — чтобы не вводить ключ каждый раз на своём телефоне/компьютере.
3. **Выполненные работы** → **Добавить работу** → название, направление, тип объекта,
   описание, фото (можно несколько; звёздочка — обложка) → **Готово**.
4. **Отзывы** → перетащите скриншоты (или нажмите на рамку и выберите файлы с телефона).
   Имя клиента, объект и текст — по желанию.
5. Внизу появится тёмная полоса → **Опубликовать на сайт**.
   Через 1–2 минуты изменения будут на сайте.

Стрелки ↑ ↓ — порядок, глаз — скрыть/показать, корзина — удалить.
Фото с телефона можно грузить как есть — админка сама уменьшит их.

Разделы «Наши работы» и «Отзывы» (и пункты меню к ним) **появляются на сайте автоматически**,
как только опубликована первая работа или первый отзыв. Пока их нет — разделы скрыты,
чтобы на сайте не было пустых блоков.

## 4. Запасной способ — без админки

Можно просто загрузить фото через сайт GitHub:
откройте в репозитории папку `uploads/reviews` (или `uploads/works`) →
**Add file → Upload files** → перетащите фото → **Commit changes**.
Сайт сам покажет их (работы — с названием из имени файла). Подписать их потом можно в админке:
она покажет плашку «нашлось N фото, загруженных вручную».

> Если папки `uploads` в репозитории ещё нет: создайте её у себя на компьютере
> (`uploads` → внутри `reviews` → внутри фото) и перетащите **всю папку `uploads`**
> в окно **Add file → Upload files** — GitHub сохранит вложенность.

## Частые вопросы

- **Открыл index.html на компьютере — нет работ и отзывов.** Это нормально: они подгружаются
  только когда сайт открыт по адресу на GitHub. Всё остальное работает и локально.
- **«Ключ доступа не подошёл».** Ключ скопирован не целиком или истёк срок — создайте новый.
- **«Нет права записи».** В настройках ключа не выбран репозиторий или не выставлено
  `Contents: Read and write`.
- **Безопасно ли, что admin.html открыт всем?** Да: без вашего ключа он ничего не может.
  Ключ хранится только в вашем браузере. Если потеряли телефон — удалите ключ на GitHub
  (там же, в Fine-grained tokens) и создайте новый.
- **Свой домен (например smolyaninov.ru).** Settings → Pages → Custom domain. Админка продолжит
  работать по адресу `ваш-домен/admin.html` (репозиторий введёте один раз вручную).
